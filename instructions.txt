Create a dns server in the java language. You can use springboot frameworks but ensure that the dns request handling is efficient and scalable.  The server should provide configurable to fetch dns entries from another defined dns server and cache them for a period of time.  However the server should also define a way to register a plugin that handles resolving ip addresses for given hostname patterns.  These should allow multiple plugins to be defined.  An example plugin could be one that looks up the ip address from a file, but also there could be an example that uses an in memory registry of ip addresses that can be defined via a rest interface.  These plugins may wish to implement round robin or other algorithms to rotate around multiple ip addresses if multiple are defined per hostname.  Write a test client and some tests for this service along with extensive documentation in a README.md file.  Include how to build and package and how to extend the system.
